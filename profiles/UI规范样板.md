# autops UI 规范（按独立规范包样板适配）

本文件依据独立规范包 `2026.10.19` 的可填写与扩展样板，登记本项目已有视觉、组件和页面约束。启用范围见[项目配置](../项目配置.md#二启用的专项规范)，接入依据见[合并说明](../docs/AI-规范合并说明.md)。本次没有重新设计 UI，也不要求实现清单中尚未采用的组件。

## 一、填写、启用与权威来源

1. [前端规范附录](../docs/AI-前端开发约束规范.md#附录项目-ui-实施标准)继续作为本项目 UI 数值和交互政策的权威来源。下文用具体章节、变量及组件引用登记规则，避免另存一套色值、尺寸或错误常量；修改权威规则时同步核对这里的映射。
2. 条目状态使用“待确认、已批准、沿用已核实实现、不适用”。“已批准”表示沿用接入前已存在的项目规范，不代表本次经过新的人工设计评审；实现存在和静态核对不代表浏览器验收通过。
3. 当前需求依赖的待确认项先查已有规范、组件和调用方；能明确复用时记录证据后沿用，无法确认时暂停对应设计决定，其余已授权工作继续。空白或待确认不授权 AI 自行选择样式、开发组件或补充默认值。
4. 颜色、布局、设备、组件和错误政策有实质冲突时按[工程治理](../docs/AI-工程治理与需求规范.md)处理，不得用导入或锁定外观删去必要状态、权限和可访问性。例外须记录原因、影响、授权和复审条件。

## 三、AI 样式实施边界

- 优先复用已批准布局、变量、组件及变体。新增页面沿同类页面结构和密度，禁止因外部技能或“美化”擅自换色、改圆角、加阴影、换图标、重排布局或加动画。
- 规则按已批准且有效的项目例外、组件专属约束、附录全局规则、已核实组件基线核对；外部设计或组件库示例不能自动填补缺项。冲突必须明确解决。
- 页面允许因已确认业务内容、数据和权限产生差异，不得自建第二套按钮、输入、状态色和间距。新变体按第八节登记，用途不明确不得添加。
- 颜色引用已确认 CSS 变量；其他尺寸和布局参数引用附录或具体组件定义。新增业务尺寸须登记用途，禁止任意行内覆盖或新全局选择器改变既有外观。
- Element Plus 通过当前锁定版本的主题入口和公共 API 映射；已有全局选择器覆盖以 `main.css` 中明确登记的组件规则为基线，新任务不得自行扩展深度覆盖、滥用 `!important` 或改第三方源码。传送到 body 的浮层仍用相同主题。
- 样式任务保留数据、请求、权限、失败和危险确认语义。加载、无数据、无结果、失败、部分完成和结果未知分别表达，禁止以空态、动画或假数据掩盖错误。
- 标题、提示、状态和操作均服务实际用户任务；禁止展示接口内部对象和无用途统计，低频有效证据可以展开，核心结果和危险影响保持可见。
