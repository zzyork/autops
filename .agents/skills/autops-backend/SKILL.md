# autops 后端实施

本文路径均相对于仓库根目录。先按 `AGENTS.md` 完整阅读三份开发规范，再从 `FILE_INDEX.md` 定位实际代码和调用方。本技能不授权架构调整、迁移或新依赖。

每项任务只加载本技能一次；与前端技能交叉引用时补齐尚未读取的内容即可。只做设计或独立审核时，仅采用相关分析与检查步骤，不执行代码实施和末尾审核流程。

## 读取与设计

1. 加载 `fastapi` 技能，并按任务读取其相关参考文件；直接读文件时从 `.agents/skills/fastapi/SKILL.md` 开始。先阅读 `docs/AI-编程接入指南.md` 的已知差异。
2. 阅读 `backend/requirements.txt`、相关端点、Schema、Service、Repository 和模型。数据库会话与依赖先检查 `backend/app/api/dependencies.py`，生命周期与执行器先检查 `backend/app/main.py` 及相关服务。
3. 追踪输入、权限、数据访问、提交或回滚、输出和失败传播。明确事务由谁拥有、后台任务是否使用独立会话、资源由谁释放，复用已有机制。
4. 修改响应或事件前查找前端 API、类型、流式消费和导出。涉及跨端行为时加载 `autops-frontend`，列清成功、失败、取消、空数据与未知结果的契约和兼容影响。
5. 说明目标、文件、边界、复用点及验证。迁移和架构变化按项目规范确认；已授权的常规实施不再逐步请求形式审批。

## 实施边界

- 保持 FastAPI + Pydantic + SQLAlchemy + Paramiko 及项目现有执行方式。上游 SQLModel、Asyncer、uv、ty 和 FastAPI CLI 偏好不采纳为迁移指令，不自动升级依赖或替换启动脚本。
- 按实际 I/O 决定同步、异步和执行器边界。普通工具函数不会因被异步路由调用就自动进入线程池；检查阻塞 SSH、数据库和文件操作，复用项目现有并发控制。
- 保留 SSH 目标身份确认、参数校验、权限、互斥、超时、取消和输出限制。任务异常不能伪造成功，未知执行结果按现有模型表达；不自动重试副作用操作或新增备用执行路径。
- 对 JSON 使用明确返回模型，对错误、SSE 与下载检查实际对外内容。上游新 SSE、前端托管及遥测 API 必须先核对固定版本和现有契约，不重写既有协议来匹配示例。
- 明确响应字段消费者，保护凭据和内部诊断信息。日志与报错只保留允许的上下文，不把第三方原始对象直接对外返回。

## 验证与交付

1. 阅读 `pyproject.toml`、开发依赖及相关测试，选择与变更相符的 pytest 用例；从根目录以项目 Python 环境运行 `python -m pytest backend/tests/具体测试文件.py`，将占位路径替换为已确认存在的文件。
2. 覆盖正常、异常、权限、边界和调用方兼容。SSH 与副作用执行使用隔离数据库及模拟目标；不因运行测试而连接真实主机或修改真实资产。
3. 未配置的 Ruff、类型检查或浏览器工具不标记为已执行；临时测试与运行产物按忽略规则处理。
4. 实施代码修改后，加载尚未读取的 `autops-review` 并执行一次审核；独立审核中不再回调。报告行为与契约变化、必要复杂度、验证和未完成项。
