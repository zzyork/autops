# 前端 UI 规范

适用于本项目所有前端页面、组件和样式。Agent 编写或修改前端时必须遵守；用户当前明确要求优先。技术栈沿用 Vue 3 + TypeScript + Element Plus。

仅面向桌面大窗口设计和验收，不做中、小窗口或移动端适配。禁止自行添加响应式断点、移动导航抽屉、按窗口宽度重排布局或将多列表单改为单列；窗口缩小时保持桌面结构。

## 视觉与布局

- 采用紧凑运维控制台布局，以蓝色主操作、石墨色顶栏、中性灰背景和浅色面板建立视觉层级。
- 顶栏高 40px，背景使用 `--ui-header-bg`，文字使用 `--ui-header-text`，保留 autops 品牌；主导航展开宽 200px、收起宽 54px，菜单项高 38px。
- 导航选中项使用主色文字和左侧 3px 指示条；主导航与页面内的分组筛选区分开。
- 内容区占满剩余宽度，背景使用 `--ui-canvas`，内边距 20px；禁止通过居中窄容器制造左右大块留白。
- 页面按“面包屑、紧凑标题、工具栏、数据区”组织；列表页以表格为核心。
- 固定顶栏只预留一次高度。明确各区域的滚动容器，避免重复偏移、内容裁切和整页横向溢出。
- 模块间距 16px，控件间距 8px；输入控件直角，小按钮圆角 2px，表格顶部可用 5px 圆角。
- 普通面板依靠背景与细边框分层，浮层可使用轻微阴影。禁止无业务用途的欢迎横幅、巨型标题、装饰卡片、渐变、玻璃效果和大圆角。

## 颜色

### 配色原则

- 配色由本项目独立制定。禁止复制、套用或以复刻为目标模仿已有软件的品牌色、主题色板及其组合关系；不得从其他产品截图、样式源码或组件库预设主题直接提取色板。
- 遵循通用颜色语义：蓝色表示主操作与信息，红色表示删除与错误，绿色表示成功，琥珀色表示警告，中性灰用于背景和次要操作。不得为追求独特而颠倒语义；借鉴设计原则不等于复制产品色板。
- 全部颜色集中为下表中的 CSS 自定义属性；页面和组件引用变量，不各自添加硬编码颜色。白色、灰色等通用颜色可以使用，禁止直接照搬其他产品的整体配色方案。
- 本规范定义浅色主题。不得自行增加另一套主题；调整颜色时同步更新变量、交互状态及对比度验证。

### 语义色板

| 状态 | 前景变量 / 色值 | 浅底变量 / 色值 |
| --- | --- | --- |
| 成功 | `--ui-success` / `#287348` | `--ui-success-soft` / `#EAF4ED` |
| 信息 | `--ui-info` / `#315F89` | `--ui-info-soft` / `#EAF1F7` |
| 警告 | `--ui-warning` / `#8A5C10` | `--ui-warning-soft` / `#FBF3DF` |
| 危险、错误 | `--ui-danger` / `#B13737` | `--ui-danger-soft` / `#FAECEC` |

- 主色用于主要操作、真实链接与导航选中，不大面积铺满内容区。导航选中采用主色文字、浅主色背景与左侧指示条。
- 同一操作区域只保留一个高强调主操作；新增、保存使用蓝色，编辑使用蓝色或中性文字按钮，刷新与取消使用中性按钮。不得将新增染红，也不得将删除染绿。
- 状态提示与标签采用对应浅底和深色前景，必须显示状态文字，可配图标；不用整行高饱和背景表达状态。
- 默认删除操作使用危险色文字，hover 使用危险浅底；实心危险按钮使用危险色背景与白字。错误输入框边界使用危险色，不能仅修改帮助文字颜色。
- 中性按钮使用面板底色、正文色和控件边框，hover 使用次级区域底色。禁用状态使用专用变量，禁止降低整个组件 opacity 导致文字与边框不可辨识。
- 键盘焦点使用主色 2px 外轮廓，偏移 2px；不能只靠 hover 或微弱背景变化提示焦点。
- 深色顶栏上的焦点轮廓使用 `--ui-header-text`，确保与顶栏背景有足够对比。

### Element Plus 映射与对比度

- `--el-color-primary` 及其 `dark-2` 分别映射主色、主色 hover；按钮按下态显式采用 `--ui-primary-active`。success、info、warning、danger/error 映射对应语义前景色。
- 背景、正文、辅助文字、placeholder、控件边框同步映射对应 Element Plus 变量；菜单、表格、弹窗及传送到 body 的浮层均应用同一主题，不残留组件库默认色板。
- 组件库需要的 `light-3/5/7/8/9` 按基础色与白色以 30%/50%/70%/80%/90% 的白色占比在 sRGB 通道混合后统一生成。交互与状态浅底优先使用明确指定的变量。
- 普通文字与背景对比度至少 4.5:1；控件边界及焦点标记与相邻背景至少 3:1。装饰性分隔线不承担控件辨识职责。
- 每次调整色板后重新核算实际组合，包括主按钮白字、顶栏文字、辅助文字、状态浅底、控件边界和焦点。透明叠加与派生色按实际背景检查。

## 字体

- 使用系统字体栈：`"Open Sans", "Helvetica Neue", Helvetica, Arial, "PingFang SC", "Microsoft YaHei", sans-serif`，不引入字体下载依赖。
- 正文 13px，行高约 1.43；辅助信息 12px，行高 18px。
- 页面标题 18px / 600，分区标题 14px / 600，弹窗标题 16px，菜单文字 12px。
- 长名称、地址和说明应可查看完整内容，不得因固定宽高丢失关键信息。

## 表格与工具栏

- 工具栏主要操作放左侧，搜索、筛选和刷新放右侧；同一工具栏控件高度一致。
- 表格文字 13px、行高 1.5，表头纵向内边距 8px、正文单元格纵向内边距 6px。
- 表头使用 `--ui-surface-muted`，正文使用 `--ui-surface`，横向分隔线使用 `--ui-border`；常规单元格不添加纵向网格。
- 单行目标高度约 36–40px，双行信息自然增高，不锁死行高。名称为主信息，地址等为辅助信息。
- 行 hover 使用 `--ui-row-hover`，选中态使用 `--ui-primary-soft`。操作列放右侧，宽表按需固定操作列并在表格容器内横向滚动。
- 名称只有在存在真实跳转入口时才显示链接样式。
- 分组筛选栏宽 220px；平面分组使用列表，不伪造层级树。
- 分页、批量操作、在线状态和统计仅在业务及数据支持时展示，不为补齐界面而虚构功能。

## 按钮与表单

- 常规按钮高 30px、字号 13px、内边距 8px 12px、圆角 2px。
- 主动作使用主色实心按钮，次要动作使用中性描边按钮，行内操作使用紧凑文字按钮，删除使用危险色。
- 输入、选择、数字输入等常规控件高 30px、字号 13px、圆角 0；多选控件允许随内容增高。
- 控件只显示单层边框，避免 wrapper 边框与 Element Plus 内嵌阴影叠加；聚焦使用主色边框，错误使用危险色边框。
- 表单按业务分区，字段间距 20px；短字段可排两列，不按窗口宽度改变列数。
- 标签与控件关联，必填标识使用 `--ui-danger`；placeholder 不能代替标签。帮助文字位于字段附近。
- 禁用状态清楚可辨；图标按钮提供可访问名称。

## 弹窗与反馈

- 弹窗在视口内居中，标题 16px，页脚右侧按“取消、保存”排列。
- 简单表单宽约 440px，复杂表单宽约 720px，均不得超过视口；长内容可滚动，操作按钮始终可达。
- 区分加载中、无数据、搜索无结果、加载失败、字段错误和保存中。
- 保存中显示 loading 并阻止重复提交；失败显示明确错误和适用的重试操作，不显示成正常空数据或成功。
- 危险操作确认说明具体对象与影响。视觉修改保留现有校验、凭据处理、冲突处理和确认语义。

## 桌面范围与可访问性

- 保持桌面侧栏、分组栏与表格的固定结构；侧栏仅由用户操作展开或收起，不随窗口宽度切换。
- 宽表格在自身容器横向滚动；桌面窗口内保证弹窗、下拉面板与操作按钮可达。中、小窗口不作为适配或验收目标。
- 保留可见的键盘焦点，支持 Tab 操作，弹窗保持合理的焦点进入与返回行为。
- 检查文字、按钮与背景的对比度；不可通过删除焦点样式或进一步缩小字号来压缩界面。

## 验收

- 页面布局、颜色、字号、控件尺寸与本规范一致，跨页面复用统一样式和组件。
- 检查加载、空数据、错误、保存中、长文本和长表单状态。
- 前端代码修改后执行项目已有类型检查与构建；具备浏览器验证条件时以 1440px 桌面窗口检查布局及交互，不执行中、小窗口适配验收，未执行的验证如实说明。

本文件为项目统一实施规范，配色独立制定，不采用已有软件的主题色板。

配色原则依据：[Atlassian 颜色角色与交互状态](https://atlassian.design/foundations/color)、[Carbon 主操作与危险按钮](https://carbondesignsystem.com/components/button/usage/)、[W3C WCAG 颜色不能作为唯一提示](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)。借鉴其语义、层级和可访问性原则，不采用其品牌色板。
