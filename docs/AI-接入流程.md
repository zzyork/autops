## 二、如何导入其他项目

1. 将本包复制或解压到独立位置，先读本说明和 [初始化清单](AI-项目初始化清单.md)，检查目标仓库已有规则、文档和工作区。
2. 已有项目逐项合并 `AGENTS.md`、`FILE_INDEX.md`、`SECURITY.md` 与对应主题，禁止覆盖或删减原规则、代码索引和产品 README。只有原本不存在且不会冲突的规范文件才直接复制。
3. 把本包 README 作为包说明保留或不复制，不用它替换产品 README；只在产品贡献指南允许的位置链接实际规范入口。
4. 新项目可以在已批准范围内采用根工作约定和规范，填写 [项目配置](../项目配置.md)，补充真实需求、入口、路径与检查；禁止拿占位配置当作既有能力。
5. 技术栈匹配且采用已获授权时，才在项目配置明确启用对应专项并合并冲突；不同框架只使用通用规则或另行批准的专项。
6. 按实际设计和设备填写 UI 规范模板的基线、变量、组件及页面组合；颜色、页长、验收视口、错误文案和消息样式须核对已批准范围和政策，不能因为文件存在自动改版或将未填写项交由 AI 自行设计。
7. 核实命令、验证和可选技能，执行低风险试运行。报告已合并内容、冲突选择及未验证项；禁止凭模板已复制宣称 CI、权限或生产能力已具备。

这些是一次接入步骤，不要求每项普通开发重新审批。用户已有授权且不存在新实质决策时继续实施。

## 三、通用规则与项目适配

| 内容 | 复用与适配边界 |
| --- | --- |
| 根工作约定 | 中文、三份核心必读、真实核实、工作区保护、小步修改、授权与人工审核；不绑定项目专用技能 |
| 奥卡姆规范 | 核心规则、必要复杂度、拆分/复用及全部 8 条文献适用边界，文献核对描述作为历史记录 |
| 前端约束与 UI 模板 | 通用职责、类型、状态、请求、信息和可访问性进入核心；Vue 独立为可选专项，UI 样板提供可填写与扩展的样式约束，不预设桌面风格或色板 |
| 后端约束 | 保留模型、分层、响应过滤、事务、迁移、并发、任务、超时与释放；FastAPI 技术行为独立为可选专项 |
| 工程治理与需求 | 保留规则冲突、验收、依赖准入、决策、授权工作流和文档/方案生命周期；真实项目基线改为待核实配置 |
| 接口与安全 | 保留契约、最小必要输出、流/下载、安全、条件性审计、密钥与未来门禁；去除固定业务事件和身份假设 |
| 测试与交付 | 保留风险检查、证据、测试本地基线、失败处理、Git、完成定义和敏感备份保护；具体命令、部署及健康路径由目标核实 |
| 编程接入指南 | 来源审核、加载核实、一次加载、只读边界、指令信任、代理/MCP 权限与长任务交接；不携带客户端配置或外部技能 |
| 工程实践参考 | 官方项目与安全资料的本次检索范围、阅读状态、采用位置和限制；不声称已安装或验证客户端 |
| 安全策略 | 保留脱敏、私密报告和泄露处置，渠道与负责人在目标配置核实 |
| 五类模板 | 保留字段、授权和本地验证要求；设备范围改用目标项目已批准配置 |
| 文件索引及 README | 包索引与接入说明不代替目标项目源码索引或产品说明 |
| 历史与示例 | 不携带其他项目名称、私有组件名、专属检测规则、机器路径及输入目录变化记录；保留必要参考出处 |

数据库与迁移方式、进程数、认证模式、业务字段、私有组件和部署目录由目标项目核实，不设通用默认值。错误“系统异常”仍由项目明确选择；UI 样式及设备数值由目标项目在模板中确认。

测试及验证脚本仅本地、临时方案完成后删除、README 模块及 1000 字要求作为本包基线保留；已有项目相反政策先合并决策，禁止导入直接批量改动其测试跟踪或目录结构。

## 四、未附带与未验证的能力

包内没有应用代码、测试、依赖环境、秘密、运行数据、构建产物、安装/部署脚本、CI、分支保护、外部技能或客户端权限设置。文件存在不表示目标项目有指定框架、组件、认证、数据库或检查命令。

本包维护检查规范内容、结构、引用与适配，不对未知目标项目运行应用测试或提供上线结论，也不因目录维护就声称已生成或验证归档。目标项目的实现、工具和客户端加载仍按其配置验证。新依赖、外部系统操作、生产发布等不因复制规范自动获准。

## 五、来源、许可与参考限制

现存论文和工程文章引用的历史核对日期、全文/摘要范围仍按各自记录保留，未逐篇重新验证。2026-10-19 新增的 AI 编程项目与安全资料检索单独记录在 [工程实践参考](AI-编程工程实践参考.md)，明确正文已读、仅摘要和抓取失败的边界。采用具体 API 或版本建议前查证官方内容与目标依赖，禁止把历史记录称作本次新调研、安全认证或官方背书。

社区搜索结果可用于发现问题，未核对内容不作为强制条款依据。本包未新增开源许可证或代为授予第三方材料权利；后续公开分发由维护者核实授权，维护本地文件不自动授权发布到外部平台。
