# 服务器运维

六个独立入口位于侧栏“服务器运维”，地址分别为 `/operations/hostname`、`packages`、`firewall`、`kernel`、`system`、`disk`。不包含 OpenSSL，本期不接入 AI 写操作。

## 使用流程

1. 在资产管理登记主机并完成 SSH 主机密钥信任。
2. 选择单台或多台主机。读取现状仅支持一台；计划最多 16 台。
3. 选择操作并填写参数。非 root 写操作需显式勾选免密 sudo；不收集 sudo 密码。读取现状也可显式使用 sudo。
4. 准备计划仅执行权限检查和只读预检。核对目标、参数、前置状态、步骤及影响后，通过独立按钮确认执行。
5. 后台逐主机、逐步骤执行，详情显示输出、退出码和核验结果。历史支持模块筛选及 10/20/50 条分页。

计划有效期 30 分钟；确认后使用已保存的命令，不能修改参数。执行前重新核对资产快照和远端预检摘要，变化时停止。每项写操作需要 root 或预先配置的免密 sudo。

## 功能及边界

| 模块 | 操作 | 边界 |
| --- | --- | --- |
| 主机名 | 查询、设置、可选维护 hosts 条目 | 只修改远端名称，不同步资产名称；hosts 地址显式填写，保留其他条目 |
| 软件包与仓库 | 指定包/预设基础包安装、指定/全量升级、仓库查询与增删改 | 使用 DNF；仓库只修改目标段，新增强制 GPG 校验；URL 不接受账号、密码和查询参数 |
| 防火墙 | 启停、自启、服务/端口规则增删、reload | 明确运行态/持久态；停止时使用 offline 工具管理持久态；复杂规则无法证明 SSH 通路时拒绝操作；不会自动 reload 持久规则 |
| 内核参数 | 数值型 sysctl、limits | 专属 `/etc/sysctl.d/90-autops.conf` 和 `/etc/security/limits.d/90-autops.conf`；sysctl 先应用再持久化，后者失败时运行态可能已变化；limits 仅核验配置，下次符合 PAM 配置的会话生效 |
| 系统优化 | chrony、root vimrc、SELinux | chrony 需已安装，保留原有时间源，核验整体同步及新源可达；vimrc 保留非受管内容；SELinux disabled 的持久状态需重启，不自动重启 |
| 磁盘 | 查询、裸盘初始化并挂载 | 一次收集设备、VG、LV、XFS/ext4、挂载点和 fstab 参数；整盘全部容量建一个 LV；必须有稳定 by-id、无分区/签名/挂载/LVM/RAID/swap/系统用途；仅允许 `/data`、`/mnt` 下父目录已存在的新目录 |

仅支持 `/etc/os-release` 标识为 RHEL 系或 Fedora 系且已具备 DNF 的目标。常规 CentOS 7、Debian/Ubuntu 和容器环境不在本期支持范围。各操作还要求对应工具存在；缺失时预检失败，不自动安装缺失工具或切换实现。磁盘需要 LVM、parted、mdadm、udev 和所选文件系统工具。不同发行版的工具版本、firewalld policy、SELinux 和文件系统实际行为仍需在指定测试主机验收。

## 执行与失败

- 本地单实例、单 worker；两条执行线程，最多 32 台活跃或排队主机。同一主机的运维任务互斥。
- 失败停止该主机后续步骤；其他主机独立执行。任务详情保留已经完成的步骤。不自动重试、回滚、恢复快照或重启主机。
- 非零退出可能发生在部分修改之后，失败不等于未改变远端；以逐步骤记录和实际核验为准。
- 超时、断连或输出超限可能意味着远端命令仍在运行。此时显示“结果未知”，持久阻止该主机的新写任务，重启后仍保留阻塞；只读查询仍允许。
- 人工通过带外方式确认远端进程停止后，在原任务详情填写核对说明并解除阻塞。此操作仅解除后续写入限制，不把历史结果改成成功，也不会重试。
- 服务重启时未开始的任务标记中断，已开始但结果未记录的主机标记未知。数据库持久化异常后停止接受后续任务。
- 输出有限长展示，URL 遮蔽。不要将凭据放入自定义主机名或其他运维参数；输出仍需按运维记录保护。

## API 与数据

接口前缀 `/api/v1/operations`，精确请求响应可见 FastAPI `/docs`：

- `GET /catalog`、`POST /inspect`。
- `POST /plans`、`POST /tasks/{id}/confirm`。
- `GET /tasks`（module/page/page_size）、`GET /tasks/{id}`。
- `POST /tasks/{id}/hosts/{host_id}/resolve`：提交计划 ID、`remote_stopped=true` 和 5–500 字核对说明。

计划、主机执行和步骤记录保存在既有 SQLite 的 `operation_tasks`、`operation_hosts`、`operation_steps` 表。启动执行幂等建表和新增核对字段迁移，不导入旧项目 output.log。现有应用没有身份认证和多用户授权，适用范围仍是本地单实例控制台。

## 验证记录

采用隔离 SQLite 和模拟 SSH 验证参数、确认防重、过期、状态变化、失败停止、未知阻塞/解除和重启；生成的全部动作脚本通过 Git Bash 语法检查。未连接真实主机执行写操作，尚未完成真实 RHEL/DNF 环境及浏览器交互验收。使用前需人工审核。
