# AI 对话使用说明

## 模型连接

进入侧栏“模型配置”新增连接，填写名称、接口协议、服务地址、模型 ID、可选 API Key 和默认连接。支持任意实现所选协议的模型服务，不绑定厂商。连接保存后可运行能力测试，分别显示对话和工具调用状态。只有工具调用测试通过才向模型开放运维工具；测试不会执行远程命令。

OpenAI 兼容地址填写 API 根路径，例如 `https://api.openai.com/v1`、`http://127.0.0.1:11434/v1` 或实际内网服务地址，系统在后面追加 `/chat/completions`。Anthropic 地址填写 `https://api.anthropic.com` 或以 `/v1` 结尾的服务地址。模型 ID 手动填写服务支持的准确名称。服务须支持 SSE 流式响应和协议终止事件，工具能力还取决于具体模型。

API Key 在后端使用现有 Fernet 密钥加密保存，响应只返回是否已有密钥。编辑时留空保留原密钥；无密钥本地服务可留空。不跟随模型 HTTP 重定向，不自动切换厂商或备用模型。更改协议、地址、模型或密钥会清除能力测试状态，并要求已有会话新建；更改连接名称或默认标记不影响已有会话。

## 对话与巡检

1. 首页或 `/ai/chat` 选择连接，创建会话。
2. 输入运维问题，支持 Ctrl+Enter 发送，单条最多 8000 字；回复实时展示。
3. 输入“查询 production 分组的主机”或“帮我对 production 分组所有服务器进行巡检”。模型查询真实资产，再生成巡检计划。
4. 查看计划的主机名称、地址及检查项，点击确认或拒绝。模型不能自行确认，确认前不会发起巡检。
5. 确认后查看关联任务卡片、进度、执行状态、健康结论及展开的巡检详情。也可继续询问本会话任务的结果。

现有“分组”作为项目服务器范围，尚未建立独立项目模型。模糊分组匹配有歧义时需要澄清；按名称或 IP 地址查询主机。巡检沿用现有规则和单任务 32 台上限，不自动分批。首次 SSH 信任或资产变更仍按已有巡检边界处理。

计划的主机必须来自本会话成功的资产查询，确认时再次校验资产版本。重复同向确认返回原任务，不会创建第二个任务；拒绝后不能再确认同一计划。计划确认与任务记录在同一事务内保存，后台投递失败明确标记未投递部分为中断，不重试。

会话固定使用创建时选择的模型连接，历史由后端保存，刷新可恢复。删除会话会删除对应消息、工具历史和计划，但不删除已创建的巡检任务。连接关联会话时不能删除。消息请求失败保留输入，历史明确标记失败或中断，失败消息不作为后续成功上下文；页面会重新读取会话以核对服务端状态，不自动重发。

## 数据与执行边界

- 模型服务会收到用户输入、成功的历史对话，以及任务所需的资产 ID、名称、地址、分组、版本和巡检结果。选择服务前考虑这些数据的发送范围。
- 模型不接收主机密码、SSH 私钥、跳板机凭据或 API Key 作为对话内容；API Key 仅用于请求所选模型服务。
- 当前只注册资产查询、准备巡检计划和读取本会话关联任务；没有任意 Shell、安装、删除资产、修改规则或信任指纹工具。
- nginx 等安装能力尚未迁移。旧项目安装流程需要另外定义受控任务、版本、权限及服务变更范围，不能在当前对话执行。
- 运维任务异步执行，关闭页面不取消已确认的巡检。模型回复不能替代任务实际状态；执行完成也不代表健康正常。
- 运行形态沿用本地单实例、单 Uvicorn worker。尚无身份认证、RBAC 或完整操作审计，不应直接作为多人共享的运维入口。
- 模型输出当作不可信文本展示，不渲染动态 HTML；模型调用限制轮数、响应大小、上下文和总时限，错误不回显厂商敏感原文。

## 接口和依赖

前缀 `/api/v1/ai`：

| 接口 | 用途 |
| --- | --- |
| `GET/POST /connections` | 查询、创建连接 |
| `PUT/DELETE /connections/{id}` | 更新、删除连接 |
| `POST /connections/{id}/test` | 对话及工具能力测试 |
| `GET/POST /sessions` | 查询、创建会话 |
| `GET/DELETE /sessions/{id}` | 会话详情、删除 |
| `POST /sessions/{id}/messages` | SSE 消息，事件 token、done、error |
| `POST /sessions/{id}/proposals/{id}/decision` | 确认或拒绝计划 |

后端使用 HTTPX 访问模型，LangGraph 编排模型与工具循环；SQLite 保存连接、会话、消息、批次工具历史和计划。新增表通过启动迁移创建，API Key 纳入启动时的加密密钥匹配检查。没有真实模型配置时，开发测试使用模拟流响应，不访问真实服务器。
