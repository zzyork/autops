# AI 对话中止契约

2026-10-21 用户明确确认“回复及关联后台任务”，允许新增会话活动查询和停止接口。停止范围为当前 AI 会话的回复、巡检计划提交、已确认计划关联的巡检及正在生成的 AI 报告。其他会话和未关联的独立巡检不受影响。

## 按钮与状态

- 新建空会话显示创建中；回复、计划提交或关联后台任务运行时，“发送”变为 32px 红色圆形按钮，内部为白色停止方块，并提供可访问名称。
- 点击停止后显示“正在中止”，保留停止图标并阻止重复点击。执行器实际退出后恢复发送，用户输入保留。
- 活动查询失败时显示“运行状态未确认”，保留上次已知状态、禁用发送，并提供“刷新状态”；停止请求不自动重试。失败或断连可能发生在部分取消已接受之后，不能视为停止未发生或已经完成。
- 当前可见会话在有活动时每秒读取状态，停止后确认执行器退出并刷新会话历史。切换会话、隐藏页面和卸载会清理状态请求及定时器，过期响应不改写当前会话。
- 返回可见页面、窗口重新获得焦点，或任务卡读取到活动巡检/报告时重新核对状态。没有跨窗口即时推送；其他窗口在当前会话空闲时启动关联报告，需重新聚焦窗口或使用任务卡的“刷新报告状态”触发状态同步。

## API

| 方法与路径 | 用途 | 成功响应 |
| --- | --- | --- |
| `GET /api/v1/ai/sessions/{session_id}/activity` | 查询当前会话执行器活动 | HTTP 200，`{"running": true, "stopping": false}` |
| `POST /api/v1/ai/sessions/{session_id}/stop` | 对当前会话和关联后台任务发送取消信号 | HTTP 200，相同活动结构 |
| `POST /api/v1/ai/sessions/{session_id}/operations` | 在实际消息/决策提交前登记可取消操作 | HTTP 201，`{"operation_id": "UUID"}` |

`session_id` 为 UUID；上述三个接口均无请求正文。当前前端为每次消息和计划决策先登记操作，然后将响应中的 `operation_id` 放入实际提交正文。消息和计划决策的 `operation_id` 为可选 UUID，既有未传入的客户端继续沿用原取消边界；每个标识只用于一次提交，不可用于重试或重新发送。

会话不存在返回 404，参数校验及其他失败沿用项目 HTTP 错误契约。停止接口幂等，无活动或重复停止仍返回当前状态，不新增任务、重试或补偿。停止移除尚未开始的操作登记；带标识的实际提交必须匹配当前未开始登记，否则返回 409，不能在停止后重新获取执行资格。前端在停止意图产生后不再启动后续提交，等待登记请求结束后停止当前会话；已发出的实际提交等待响应及活动状态确认，不把中止 HTTP 当作服务端任务已退出。

会话执行器最多登记 128 个操作，已运行操作在实际退出后释放。未启动登记有效期沿用对话整体时限 300 秒；后续登记、提交和活动查询会清理过期登记，过期或已停止的标识始终被拒绝。登记失败或客户端在登记期间断连不会自动启动模型、巡检或其他任务；仅剩未启动登记时可通过停止释放，或等待过期。容量满时新登记返回 503；停止不占新增容量，不自动重试。

`running` 表示当前会话回复/决策仍有待提交登记、运行或清理，或关联巡检/AI 报告的本地执行器仍在排队、运行或清理。`stopping` 表示其中仍有活动的取消信号已设置，始终满足 `stopping => running`。停止响应不是任务回滚凭证；`running=false` 只确认这些本地执行器已退出或未启动登记已失效，不证明历史持久化、外部模型或远程命令成功。持久化故障继续由原巡检/报告接口表达，不以无关任务的持久化故障阻断停止信号受理。

接口沿用项目现有访问边界；当前没有用户认证、角色或多租户体系。活动状态及取消协调基于既有单进程执行器，不声明支持多实例协调。既有会话详情与 SSE `token`、`done`、`error` 契约不变。

## 执行与资源边界

ChatManager 按会话持有取消信号，回复和逐项工具调用检查信号；会话互斥在生产线程退出后释放。计划提交在任务关联提交前及创建后检查取消，覆盖停止与任务创建同时发生的情况。前端身份检查和决策请求接收同一操作的取消信号，避免取消后继续提交。

巡检任务为全部主机共用取消信号。排队主机取消后不再建立 SSH 连接；运行中的命令使用既有 SSH channel 取消，停止后续检查并将未执行检查记为中断，保留已完成检查。任务在主机执行和报告交接结束后释放活动登记。

自动报告沿用巡检的取消信号，报告提交回调在巡检全局锁外执行，避免新增全局锁与数据库写锁的反向等待。取消发生在巡检完成及报告认领之间时，不继续调用模型；已认领的报告按现有中断状态结束，历史成功报告保留。

模型请求和 SSH 建连使用既有有界协作式取消，可能等待当前读取或建连阶段结束。SSH 命令取消关闭本地 channel，不证明远端已派发进程退出，也不撤销其副作用；详见 [SSH 命令执行工具库](SSH命令执行.md)。
